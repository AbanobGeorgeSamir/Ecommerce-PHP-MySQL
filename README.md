# 🛒 E-Commerce (PHP & MySQL)

A full-featured PHP & MySQL e-commerce website with product browsing, user authentication, shopping cart, checkout, order management, and an admin dashboard.

## ✨ Features

- 🔐 User registration, login, and session management
- 🛍️ Product catalog with categories and search
- 🛒 Shopping cart with quantity management
- 💳 Checkout and order placement flow
- 📦 Order history for customers
- 🔧 Admin dashboard — manage products, categories, and orders

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend | PHP (native) |
| Database | MySQL |
| Frontend | HTML5, CSS3, JavaScript |

## 🚀 Getting Started

### Prerequisites

- PHP 8.0+
- MySQL 8.0+
- A local server (XAMPP, Laragon, or similar)

### Setup

```bash
git clone https://github.com/AbanobGeorgeSamir/Ecommerce-PHP-MySQL.git
```

1. Import the SQL file into your MySQL database
2. Copy `config.example.php` to `config.php` and set your DB credentials
3. Point your local server root to the project directory
4. Open `http://localhost/Ecommerce-PHP-MySQL` in your browser
